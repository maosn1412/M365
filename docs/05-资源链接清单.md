## 本机工具速查

| 工具 | 命令/入口 |
|---|---|
| Node 版本切换 | `nvm list` / `nvm use 22.23.4` |
| SPFx 项目示例 | `D:\个人资料\项目\M365\spfx-hello\spfx-hello` |
| SPFx 本地服务 | 项目目录下 `npm run start` |
| M365 CLI | `m365 login` → `m365 entra user list`（列用户）/ `m365 request --url '...'`（任意 Graph 调用） |
| Agents Toolkit CLI | `atk -h` |
| VS Code 扩展 | Microsoft 365 Agents Toolkit（活动栏图标） |
